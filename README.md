# Jardim em Casa

Hotsite fictício para praticar Git e GitHub. Apenas HTML e CSS, sem JavaScript, pacotes, fontes externas ou imagens para baixar.

## Executar
Abra `index.html` com dois cliques no navegador. Edite no VS Code, salve e atualize a página.

## Arquivos
- `index.html`: textos, links e estrutura.
- `style.css`: cores, fontes, espaçamentos e adaptação para celular.

## Pequenas mudanças para praticar
1. Altere o título principal e confira no navegador.
2. Troque a cor `--accent` no início de style.css, mantendo o texto legível.
3. Acrescente um quarto item na seção escolha sua próxima companhia.
4. Acrescente seu nome ao rodapé.

Faça uma mudança por commit. Use uma branch para uma melhoria e apresente o resultado em um pull request.

## Clonar
No GitHub, copie a URL HTTPS em Code. No terminal, fora de outro repositório:

```powershell
git clone URL_COPIADA_DO_GITHUB
```

Substitua o texto pela URL real. Abra a pasta criada no VS Code. Um clone já contém o repositório Git: não execute init novamente.

## Baixar ZIP
No GitHub, use Code → Download ZIP e extraia antes de abrir. O ZIP contém os arquivos, mas não o histórico Git. Para trabalhar com branches e enviar commits, use clone.
